# Linux Omen Hardware ConTroL (LOCTL)

Linux Omen Hardware ConTroL (LOCTL) will be a reimplemented kernel module/driver in a way that ensures all settings comply with OEM standards, and with a reasonably aesthetic front-end and testing suites.
